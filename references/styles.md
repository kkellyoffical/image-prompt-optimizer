# 按成品选画法

下面的例句为项目自拟。先用任务里的真实对象替换主体，再到目标模型页决定如何组织输入。每一行的验收项都可以直接用来比较不同模型的成图。

| 想得到的成品 | 可以直接迁移的写法 | 优先检查 |
| --- | --- | --- |
| 光栅或版画海报 | 桥体的体积由黑色连续细线的局部弯曲显现；天空处线条逐渐拉平。若改做版画，从桥身、水面和天空各取一色，将纹理转成套色边缘。 | 缩小能辨认桥塔，放大能看清线条走向。 |
| 旅行纸品、编辑拼贴 | 保留原照中的一道海岸线，让下半区手工撕纸的纤维沿同一曲线接续；留出一整块纸面承载短标题。 | 上下画面接得上，留白仍足以排字。 |
| 写实建筑与室内 | 固定底模门洞、地面交线及消失点；用外部参考控制窗光方向，把材质只落在指定构件上。 | 将原图叠在成图上检查开口、镜头和家具比例。 |
| 电商与材质摄影 | 陶瓷瓶的厚釉面映出一条宽柔光带，金属泵头保留窄亮边；白底保留接触阴影，将标签朝向镜头。 | 标签逐字正确，陶釉和金属的反光可区分。 |
| 叙事插画与连环画 | 三格分别表现“伸手、接住、放下”，用衣领缺口和背包搭扣锁定角色，统一傍晚侧光；每格换一个景别。 | 三个动作的时间顺序可读，角色特征稳定。 |
| 胶片感人像与电影剧照 | 让潮湿路面反射街角暖灯，人物侧脸由蓝灰天光勾出轮廓，暗部保留织物和皮肤纹理。 | 肤色自然，光源方向可从倒影追溯。 |
| 中文排版、展览海报 | 标题分两行占左上方空白；次级文案沿左边对齐，笔画与底色有明确明度差，照片只裁切到主体外缘。 | 逐字逐行对照文案，缩小后标题仍可读。 |
| 结构图鉴与产品拆解 | 构件沿同一投影轴平移展开；材料色样沿边排列，每根引线只连接一个部件。 | 构件顺序、编号和色样一一对应。 |
| 等距微缩、纸雕模型 | 从原物挑三处辨识特征，以折纸棱边和纸板断面建模，让投影落在同一张小底座上。 | 剪影可辨，各面的厚度和投影方向一致。 |
| 局部换材质 | 将现有台面沿水槽开孔和墙面收边换成细粒石英石；保留台面厚度、龙头轮廓、柜门颜色和原窗光。 | 差异集中于指定区域，新材料继承现场光向。 |

照片二创、空间转绘和图鉴的案例可回看[小红书原帖索引](vision-cases.md)。产品、排版与角色的其他公开示范见[创作者与案例](creators.md)。
