# Midjourney

把案例写成一段可视化描述，按主体、媒介、构图和关键色材推进。工业场地复古拼贴可从“档案摄影剪片、混凝土厂房、道路消失点、低饱和土色与白纸留白”起草。定位编辑任务时先确认用户接下来的入口支持所需编辑方式。

有风格参考时使用目标界面的 Style Reference。Discord 支持在提示末尾附 `--sref` 与参考链接，Web 使用相应的参考图槽位。参考图只承担指定的视觉用途。提示里保留用户的新主体及场景。将经目标版本核对的参数放在末尾，避免照抄历史帖的参数。 [Midjourney Style Reference](https://docs.midjourney.com/hc/en-us/articles/32180011136653-Style-Reference)
